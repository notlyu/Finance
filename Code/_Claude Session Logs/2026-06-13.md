### Сделано: приватность семейного дашборда (F4-хвост + F5 backend)
- Разбор: семейные агрегаты подмешивали личное участников. Реальная утечка — `getFamilyBalance` суммировал ЛИЧНЫЕ счета всех участников (family_id=null) в семейный баланс → партнёр видел баланс личных счетов другого. По транзакциям утечки не было (личные tx имеют family_id=familyId, а клаузы требовали family_id=null — не совпадало), но клаузы были мёртвые/вводящие в заблуждение.
- Решение (модель «общий котёл», В6): семейные агрегаты = **только семейное**.
  - `getFamilyBalance` — только семейные счета + scope family/shared.
  - `getMonthTotals` (family) — только family/shared.
  - `getFamilyReserved` — только семейные цели/желания.
  - `memberStats` (вклады) — только family/shared (личное участника больше не раскрывается).
- Прозрачность дашборда не касается — она про видимость отдельных операций в списке (F3).
- Тест: `tests/dashboardPrivacy.test.js` (баланс без личного счёта партнёра / итоги месяца без личного расхода / memberStats без личного). Бэкенд **303/303**, lint чистый.
